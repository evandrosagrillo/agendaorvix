# Agenda Orvix

Como gerar o APK (sem instalar nada no PC):
1. Crie uma conta gratuita em github.com e um repositório novo (pode ser privado).
2. Envie TODO o conteúdo desta pasta (inclusive a pasta oculta `.github`) para o repositório.
3. Abra a aba **Actions** > "Build APK" (roda sozinho; ou clique em "Run workflow").
4. Ao terminar (uns 3-5 min), abra a execução e baixe **Agenda-Orvix-APK** em "Artifacts". Dentro vem o Agenda-Orvix.apk.
5. No celular: abra o APK e permita "instalar de fontes desconhecidas".

Dica: nas configurações do Android, deixe o app sem otimização de bateria para os alarmes dispararem sempre.
